SNS に疲れたあなたへ。もっとシンプルで、もっと自由な楽しみ方を。

かわいいシールを集めて、自由にデコって、誰かと交換しよう。

## 対象ユーザ

- SNS に疲れた、癒しを求めたい人
- かわいいシールを使ったシール帳を作ってみたい人

## 利用の流れ

アプリを開くと、「わたしのシール帳」が表示されます。
この画面では自分が持っているシールでシール帳を自由にデコることができます。

作ったシール帳は公開することもでき、公開すると「みんなのシール帳」に表示され他のユーザーがあなたのシール帳を閲覧できるようになります。

### 主要機能

#### わたしのシール帳

- 自分が持っているシールをシール帳にデコれる
- シールを種類ごとに整理
- 自分のシール帳はみんなに公開することも

#### みんなのシール帳

- 公開されたみんなのシール帳を閲覧できる
- 「すてきだね」機能により、好きなシール帳にリアクションできる

#### シールを集める

- ガチャでシールを集めることができる
- みんなと交換で集めることができ、シールをあげる側は合言葉を発行し、シールをもらう側はその合言葉を入力することでシールを交換できる

#### ネームプレート作成（設定）

- ネームプレートを作成することができ、自分のプロフィールをカスタマイズできる
- 自分が持っているシールで可愛くデコることもできる
- みんなのシール帳画面での自身のネームプレートとして使われる

## 推しポイント

- シール帳アプリは競合が少なく、新規性が高い
- シール帳が流行っている昨今のトレンドにマッチ
- 物理では難しい遠距離のシール交換をアプリで実現し、コミュニケーションを拡張

## 開発技術

### 利用したプログラミング言語

### 利用したフレームワーク・ライブラリ

Flutter

- iOS と Android の 2 つの OS に対応したアプリを効率的に開発するために採用した。

UI・デザイン関連

- google_fonts
  - 本アプリの雰囲気に合うかわいいフォントを利用するために採用した。

Firebase 関連（バックエンド）

- firebase_core
  - Firebase を Flutter アプリで利用するための基本ライブラリであり、Firebase を用いた開発に必要なため採用した。
- firebase_auth
  - Firebase の匿名認証 (Anonymous Authentication)を利用するために採用した。
- cloud_firestore
  - 交換機能の実装、全世界のユーザの公開状態のシール台紙を見ることができる機能を実装するために採用した。基本的にこれらの機能は、Flutter 側から Firebase にデータの追加・読み取り・削除・更新を要求する形で実現している。
