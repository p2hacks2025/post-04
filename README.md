## 対象ユーザ
- SNSに疲れた、癒しを求めたい人
- かわいいシールを使ったシール帳を作ってみたい人

## 利用の流れ

アプリを開くと、「わたしのシール帳」が表示されます。
この画面では自分が持っているシールでシール帳を自由にデコることができます。

作ったシール帳は公開することもでき、公開すると「みんなのシール帳」に表示され他のユーザーがあなたのシール帳を閲覧できるようになります。

### 主要機能

#### わたしのシール帳
- 自分が持っているシールをシール帳にデコれる
- シールを種類ごとに整理
- 自分のシール帳はみんなに公開することも

#### みんなのシール帳
- 公開されたみんなのシール帳を閲覧することができる
- いいね機能により、好きなシール帳にいいねすることができる

#### シールを集める
- ガチャでシールを集めることができる
- みんなと交換で集めることができ、シールをあげる側は合言葉を発行し、シールをもらう側はその合言葉を入力することでシールを交換できる

#### ネームプレート作成（設定）
- ネームプレートを作成することができ、自分のプロフィールをカスタマイズできる
- 自分が持っているシールで可愛くデコることもできる
- みんなのシール帳画面での自身のネームプレートとして使われる

- 流行に乗っている

### 利用したフレームワーク・ライブラリ

Flutter
 - iosとandroidの2つのOS環境どちらでも動くことを目指したため採用した。

UI・デザイン関連
 - google_fonts
	 - かわいいフォントを利用するために採用した。

Firebase関連（バックエンド）
 - firebase_core
	  - FirebaseをFlutterアプリで利用するための基本ライブラリであり、Firebaseを用いた開発に必要なため採用した。
 - firebase_auth
	  - Firebaseの匿名認証 (Anonymous Authentication)を利用するために採用した。
 - cloud_firestore
	  - 交換機能の実装、全世界のユーザの公開状態のシール台紙を見ることができる機能を実装するために採用した。基本的にこれらの機能は、Flutter側からFirebaseにデータの追加・読み取り・削除・更新を要求する形で実現している。
